Portfolio Project
=================

This project is a full-stack personal portfolio website built to showcase my software engineering work, technical skills, and design approach.  
It was developed using React for the frontend and Flask for the backend, with deployment managed through Render on a custom domain.

The site highlights selected projects from my portfolio, provides information about my technical background, and includes a working contact form 
that delivers messages through a Flask-based email service.

---

Live Site  
----------
https://www.sachinportfolio.com  
(Frontend and backend hosted together on Render)

---

Overview  
--------
The portfolio demonstrates practical experience with full-stack web development, responsive design, database integration, and production deployment.  
It integrates a modern React frontend with a Flask backend connected to a PostgreSQL database for project management.

This project was designed to:
- Serve as a professional online portfolio and contact point.  
- Demonstrate full-stack development with Flask, React, and PostgreSQL.  
- Implement secure form handling, dynamic data retrieval, and domain-restricted API access.  
- Maintain consistent performance and accessibility across devices.

---

Tech Stack  
-----------
Frontend  
- React (Create React App)  
- CSS for layout, animations, and responsive styling  

Backend  
- Flask (Python)  
- Flask-Mail for contact form handling  
- Flask-CORS for domain-based API control  
- Gunicorn as the production WSGI server  
- PostgreSQL database for project data  

Deployment  
- Hosted on Render  
- Integrated React build served by Flask  
- Custom domain with SSL configuration  

---

Features  
--------
- Responsive React frontend  
- REST API for retrieving project data from PostgreSQL  
- Contact form with Flask-Mail integration  
- Secure backend deployment on Render  
- CORS configuration for multiple domains  
- Combined build and deployment workflow for full-stack hosting
